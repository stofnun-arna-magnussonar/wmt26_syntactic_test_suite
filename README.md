# wmt26_syntactic_test_suite
This repo contains Árni Magnússon Institute’s team submission to the WMT26 test suite subtask, focusing on English→Icelandic syntactic constructions.

The test suite consists of 345 sentences in English over twenty categories, with each category focusing on a specific syntactic phenomenon which behaves differently in English and Icelandic. 

The test items were constructed by hand at the Árni Magnússon Institute and proof-read by a native speaker of English. For more information, see our (upcoming) paper in the proceedings of WMT2026.
